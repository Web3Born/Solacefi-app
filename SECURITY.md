# Security policy

SolaceFi is an early-stage prototype. It runs on demo data and Aleo testnet only. **Do not use it with real money.**

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

- Use GitHub: **Security tab > Report a vulnerability** (private vulnerability reporting), or
- email **Solacefipay@gmail.com** with the subject "SolaceFi security".

Include what you found, how to reproduce it, and the app version (shown on the lock screen and in Settings > About).
We aim to reply within 7 days. Please give us reasonable time to fix a problem before sharing details publicly.

## Scope

In scope: the app code in this repository, the Firestore rules, the Android build workflow, and the Aleo wallet integration.
Out of scope: third-party services (Firebase, Dynamic, Vercel, Aleo network) and social engineering of maintainers.

## Please do not

Access other people's data, run denial-of-service tests against our live services, or test with real funds.
