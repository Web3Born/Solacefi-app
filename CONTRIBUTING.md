# Contributing to SolaceFi

Thanks for helping. SolaceFi is a privacy-first payments prototype for Africa, built on Aleo.

## Ways to help
- Report bugs and usability problems (use the issue templates).
- Review the Leo and wallet integration code, especially transfer and record handling.
- Improve docs and translations.
- Test on real phones and tell us what confused you.

## Ground rules
- Be honest in code and docs: label demo features as demo, never claim "anonymous", "audited" or "first".
- No secrets in commits. Config values go in environment variables (see FIREBASE-SETUP.md and ALEO-WALLET-SETUP.md).
- Keep changes small and explain why in the pull request.
- Run `npm run build` before opening a pull request.

## Sign-off (DCO)
Add `Signed-off-by: Your Name <you@example.com>` to each commit (`git commit -s`). This confirms you wrote the change or have the right to submit it under Apache-2.0.

## Security problems
Do not open a public issue. See SECURITY.md.
